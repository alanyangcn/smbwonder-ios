# 接续审查：另一会话的 Metal 2 改动

目标：Wonder 1.2.0（update 262144）；FlyMe / iPhone 8 Plus / A11 / iOS 16.7.16。
本目录没有 Git 元数据；本次按当前源码、宿主测试、目标 main/sdk 反汇编和独立轮次日志审查，不能提供完整历史差异。

## 已确认并修复

1. `nvnMemoryPoolFlushMappedRange/InvalidateMappedRange` 拒绝 CPU_NO_ACCESS，导致 round17 停在 main+0x428ce4。目标 SDK 的 Flush 入口 0x453870 跳到 0x4539a0，Invalidate 在 0x4539cc；两者先测 CPU_CACHED(bit2)，没有此位直接返回。去除错误的 CPU_NO_ACCESS 拒绝，保留宿主范围保护。增加回归测试。
2. `TextureView` 错用参考头文件的 40 字节大小。目标 SDK 0x45bee0 只清零 16 字节；main+0x42cd5c 传入 sp+8 的 view，sp+0x18 紧邻 copyRegion。round18 中旧实现覆盖 copyRegion，导致 WriteTexels 拒绝参数。改为目标 SDK 的真实 16 字节布局（层、级、target、flags、format、swizzle），增加邻接 canary 和原始字节测试。
3. `TextureWriteTexels` 大坐标转字节后发生 uint32 回绕，64×16 RGBA8 上 x=1<<30 会写第一个像素。先在 texel 域检查 mip 和区域，再计算字节坐标，并检查每个块线性写入片段的剩余存储。回归负例覆盖该输入。
4. `MapVirtual` 使用 offset+size 检查，超大 size 会回绕。改用剩余长度检查，增加 0xffffffffffff0000 大小负例。
5. 虚拟映射原先只有写入者，没有解析消费者。新增内部 `wonder_nvn_pool_span`：解析到物理字节并在映射边界截断；未映射页明确停止。测试验证双虚拟页同物理页别名、解除中间页、左右残留偏移。GPU 地址仍是不可直接解引用的 token。此举不代表 Metal 贴图缓存的别名同步已完成。
6. 真机脚本安装失败后自动卸载旧 App，可能删除 Documents/未来存档。移除该自动删除分支；失败保留原 App。更正默认启动方式描述：默认附加 LLDB，不是独立冷启动。

7. `SamplerBuilderSetDevice` 错误要求先 SetDefaults。main+0x9afdc/0x9afec 实际顺序相反；sdk+0x459790 写设备指针，sdk+0x4597a0 默认值跳过头8字节。修正为保留设备关联。
8. `sdk_kernel.c` 多线程映射操作无锁，最后一个 4 KiB 页解除时可覆盖另一线程刚映射的同一 16 KiB 宿主页。可控竞争复现后以统一 mutex 修复，覆盖 QueryMemory/堆/区域表读写。
9. 子线程在 guest 栈上先公布退出再 pthread_exit，等待者可提前回收该栈。改为存活的 host 栈 setjmp 边界，先 longjmp 返回再公布退出。真实切换栈测试通过；删除 longjmp 的临时负对照触发断言。注册的主线程使用 pthread 自己的 NPDM 栈，维持独立路径。
10. Close 尚未启动的线程没有唤醒/回收；现唤醒等待并在 host 栈退出。真实 TLS/TLR 原始分配另有每线程泄漏，新增独立所有权键释放，测试覆盖 guest 改写公开 TLS/TLR key 后仍释放原分配。

11. 命令缓冲旧自定义结构将 callback 放在 +0x10，但 main+0x5c2b8 直接写该处标志，并访问 +0x20/+0x28 控制段指针。SDK+0x442ed0 清零0xa0字节、device在+0x60，回调/data在+0x68/+0x70。改为真实对象布局，验证元数据放有界、互斥的外部注册表（1024对象，Finalize未实现时不会伪释放）。AddControlMemory 按 sdk+0x4431e8 绑定控制段并保留16字节段尾；AddCommandMemory 仅支持未录制/未消耗的初始段，按照 sdk+0x44308c 绑定CPU/资源地址、范围和8 MiB段限制。未实现录制和段链接仍停止。补全原始字段、邻接canary、非法参数、录制期停止测试；原命令对象布局测试在修复前失败。

## 保留实现，但尚不能宣称验证完成

- DeviceGetInteger 的 0/1 是宿主兼容接口版本 55.15，不能作为所有 NVN 55 功能已经实现的证据。0x02–0x5F 仍主要来自 D2R/SMO 的 Tegra X1 配置；未逐项核对 API 55 与宿主可提供语义。
- StorageClass 是宿主自定义类别，不是已验证的 TX1 page kind。后续消费者只能将其作为宿主兼容标记使用。
- TextureFlushTexels 当前没有实际 Metal 消费者，不能以“统一内存”证明私有 MTLTexture 更新可见。B2 必须接上每次上传或物理存储版本/dirty 协议。
- pool_span 解决物理字节解析，不解决 GPU 写回、资源状态和 Metal 贴图缓存别名。进入真实 GPU 资源访问时须实现这些语义，或明确停下。
- 本轮对 kernel_threads 的映射竞争、退出和未启动关闭做了定向检查，但没有对 account/nfp/hid 及全部内核语义做等价验收；现有启动成功只覆盖已走到的路径。中性输入也不是可玩手柄输入。
